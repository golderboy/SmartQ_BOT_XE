#วิธีการใช้งาน
1.นำโปรแกรมไปวางไว้ที่ Startup ของตู้ Kiosk
2.เปิดโปรแกรมครั้งแรกโปรแกรมจะไปอ่าน config ที่ C:\Program Files (x86)\Smart Visit\ihos.ini
3.หากเชื่อมต่อสำเร็จ จะปิดตัวเองทันที

หน้าที่ของโปแกรม
